# Контент блогу

Увесь текст блогу живе тут. Верстки в цих файлах немає — сторінки збирає
`assemble.mjs`. Щоб додати статтю, достатньо покласти сюди ще один `.md`
файл; нічого більше в проєкті міняти не треба.

## Один файл = одна стаття

`content/posts/<slug>.md`, де `<slug>` — адреса статті: файл
`koly-vygidnishe-obminyuvaty.md` стає `/blog/koly-vygidnishe-obminyuvaty`.
Назву файлу пишіть латиницею, малими літерами, слова через дефіс.

```markdown
---
title: Долар тримається біля 44,90 — чого чекати далі
date: 2026-09-13
tag: Курси
image: images/news-1.webp
imageAlt: Долар і євро крупним планом
excerpt: Коротко, 1–2 речення. Показується на картці й у соцмережах.
draft: false
---

Перший абзац.

## Підзаголовок

Текст із **жирним**, *курсивом* і [посиланням](/#exchange).

- пункт списку
- ще один

> Цитата або важлива думка.
```

### Поля

| Поле | Обов'язкове | Що це |
|---|---|---|
| `title` | так | Заголовок. Іде в `<h1>`, у `<title>` і в картку |
| `date` | так | `РРРР-ММ-ДД`. За нею сортується стрічка (нові зверху) |
| `tag` | ні | Рубрика: `Курси`, `Валюти`, `Поради`. За замовчуванням `Блог` |
| `image` | ні | Обкладинка, шлях від кореня проєкту: `images/news-1.webp` |
| `imageAlt` | ні | Опис картинки для читалок і пошуку |
| `excerpt` | так | Анонс на картці та в `description` сторінки |
| `draft` | ні | `true` — чернетка: не потрапляє ні в стрічку, ні на сайт |
| `slug` | ні | Якщо треба адресу, відмінну від назви файлу |

### Що розуміє розмітка

`##` і `###` — підзаголовки · `**жирний**` · `*курсив*` · `` `код` `` ·
`[текст](посилання)` · `- ` список · `1. ` нумерований список · `> ` цитата ·
`---` горизонтальна лінія · `![опис](images/файл.webp)` картинка.

## Як зібрати сайт після правок

```bash
node assemble.mjs
```

Перебудовує `index.html` (три найсвіжіші статті в блоці «Новини»),
`blog/index.html` (стрічка) і по сторінці на кожну статтю в `blog/`.
Результат треба закомітити — Vercel роздає готові файли.

## Для майбутньої адмінки

Формат навмисне взято стандартний — Markdown з front matter. Будь-яка
Git-based CMS (Decap, Sveltia, Tina, Pages CMS) підключається до нього без
переробки сайту: у конфізі вказується тека `content/posts`, поля з таблиці
вище і медіатека `images/`. Редактор зберігає `.md` у репозиторій, Vercel
ловить коміт і перебудовує сайт. Єдине, що потрібно доробити, — запустити
`node assemble.mjs` на стороні Vercel (Build Command), щоб збірка
відбувалась автоматично, а не вручну.
