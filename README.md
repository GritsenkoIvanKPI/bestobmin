# BEST — обмін валют в Івано-Франківську

Сайт мережі обмінних пунктів: головна сторінка та блог. Темна
мінімалістична тема, акцентний колір — зелений (похідний від `#58A24D`).

## Запуск

```bash
node server/set-password.mjs   # один раз — пароль до адмінки
node server/index.mjs          # сайт, блог і адмінка на http://localhost:4199
```

Адмінка — на `/admin`. Розгортання, змінні середовища та опис безпеки:
[`server/README.md`](server/README.md).

Якщо потрібен лише статичний перегляд без API — `node serve.mjs`.

## Структура файлів

| Файл | Призначення |
|---|---|
| `index.html` | Головна — один самодостатній файл (HTML + CSS + JS) |
| `admin/` | Панель керування (збирається з `parts/admin.*`) |
| `server/` | Сервер: статика, API, автентифікація ([опис](server/README.md)) |
| `data/` | **Дані сайту:** курси, відділення, тексти секцій |
| `blog/` | Згенерований блог: `index.html` — стрічка, далі сторінка на статтю |
| `content/posts/` | **Тексти блогу.** Один `.md` файл = одна стаття ([як писати](content/README.md)) |
| `assets/site.css` | Спільний стиль для сторінок блогу |
| `parts/` | Вихідні фрагменти, з яких збирається сайт |
| `assemble.mjs` | Збирає `parts/*` + `content/*` → `index.html`, `blog/*` (`node assemble.mjs`) |
| `images/` | Усі зображення сайту (WebP, ≈860 КБ разом) |
| `vercel.json` | Кешування статики на хостингу |
| `images/hero-scene.webp` | Фон першого екрана зі скульптурою |
| `images/logo.svg` | Логотип у шапці та футері |
| `images/favicon.svg` | Фавікон — знак із логотипа (корона, «B», лавр) |
| `serve.mjs` | Локальний сервер для перегляду |

Редагувати можна або напряму `index.html`, або файли в `parts/` з наступним
`node assemble.mjs`.

### Що редагується з адмінки

Курси, новини, відділення й тексти секцій винесені з верстки у `data/` та
`content/`. Верстка бере їх під час збірки, а курси ще й читаються живою
сторінкою через `/api/public/rates` — тому зміна курсу зʼявляється на сайті
за секунди, без перезбірки.

| Що | Де лежить | Коли видно на сайті |
|---|---|---|
| Курси валют | `data/rates.json` | одразу |
| Статті блогу | `content/posts/*.md` | після автоперезбірки, ~хвилина |
| Відділення | `data/branches.json` | після автоперезбірки |
| Тексти секцій | `data/texts.json` | після автоперезбірки |

У `parts/*.html` редаговані місця позначені як `{{ключ}}` — підставляються
зі `data/texts.json`. У заголовках порожній рядок означає перенос, а
`**слово**` — золотий акцент; у звичайному тексті `**слово**` робить жирний.
Усе інше екранується, тож через адмінку не можна вставити розмітку.

### Блог

Статті лежать у `content/posts/*.md` — Markdown із front matter, без жодної
верстки. `assemble.mjs` робить із них стрічку `/blog`, сторінку на кожну
статтю `/blog/<slug>` і підставляє три найсвіжіші в блок «Новини» на
головній. Повний опис полів — у [`content/README.md`](content/README.md).
Формат узято стандартний, щоб будь-яка Git-based адмінка (Decap, Sveltia,
Tina, Pages CMS) підключилась до нього без переробки сайту.

## Перший екран

Три колонки, як у референсі: текст ліворуч, 3D-глобус по центру,
панель актуальних курсів праворуч.

- **3D-візуалізація** — у самому фоновому зображенні (див. нижче).
- **Калькулятор** праворуч — компактна версія того самого конвертера,
  що й у формі заявки: дві валюти, дві суми, кнопка обміну місцями, рядок
  з курсом. «Оформити заявку» переносить пару й суму у повну форму
  (`#exchange`), прокручує до неї та ставить курсор у поле імені.
- Від 1180px і нижче глобус ховається за колонки як фонова деталь,
  від 900px — стає окремим блоком зверху.

## Фон першого екрана

Фон — нерухоме зображення `images/hero-scene.webp` (1920×1072, 197 КБ):
скульптурна літера **B** з полірованого скла із золотими гранями, золоті
орбітальні кільця, монета, мокрий камінь і відбиття у воді.

- Композиція навмисно порожня ліворуч і праворуч — там лягають текст
  і панель курсів, а скульптура лишається в проміжку між ними.
- На екранах до 900px зображення стає банером угорі (щоб скульптура була
  видима цілком), а текст іде нижче по суцільному темному тлу.
- Відео з фону прибрано; `media/` більше не потрібна.

## Прапори валют

Прапори — власний SVG-спрайт (`parts/body-00.html`, ~9 КБ), вбудований у
сторінку: жодних зовнішніх запитів, іконкових шрифтів чи emoji. 12 символів —
USD, EUR, GBP, PLN, CHF, CAD, CZK, SEK, HUF, UAH, USDT і комбінований значок
для крос-курсу EUR/USD (половина ЄС + половина США).

Кожен бейдж підставляється через `<use href="#fl-…">`, тож один і той самий
прапор не дублюється в коді. Щоб додати валюту — додайте `<symbol>` у спрайт
і вставте бейдж:

```html
<span class="cur-badge">
  <svg class="flag" role="img" aria-label="Назва валюти"><use href="#fl-код"/></svg>
</span>
```

## Адаптивність

Перевірено на 19 ширинах від 320px до 1920px: без горизонтального скролу,
без накладань, без обрізаного тексту.

Мінімальні розміри, закладені у верстку:
- **жодного тексту менше 14px** на всьому сайті (15px на мобільних);
  основний текст — 17px, текст у картках — 16px;
- зони натискання — не менше 44px по висоті на екранах до 900px;
- вміст не обрізається: назви валют переносяться, а не ховаються за «…».

## Палітра

Акцент — золотий градієнт **#FBDBA2 → #CCA377 → #FBDBA2**.
Усі відтінки заведені у токени в `parts/css-00.css`:

```css
--accent-200:#fbdba2;   /* світлий стоп */
--accent-600:#cca377;   /* середній стоп, основний інтерактив */
--accent-700:#a8835c;   /* глибокий — лише для рамок, не для тексту */
--accent-grad:linear-gradient(115deg,#fbdba2 0%,#cca377 48%,#fbdba2 100%);
--on-accent:#1a1206;    /* підпис на будь-якій градієнтній заливці */
```

Сам градієнт застосовано там, де він працює як метал: виділене слово в
заголовку, великі цифри-показники, головні кнопки, логотип і фавікон.
Решта — суцільні стопи з тієї ж шкали.

Зелене підсвічування у 3D-рендерах перефарбовано у золото: зсунуто лише
зелений діапазон відтінків, тож банкноти, шкіра й теплий метал на фото
зберегли власний колір. Оригінали рендерів не потрібні для роботи сайту.

> Зеленими лишились рівно два кольори — і мають лишитись: смуга на
> прапорі Угорщини (`#477050`) та фірмовий знак Tether (`#26A17B`).

## Фон і світло

Сторінка більше не суцільно чорна. Замість цього:

- **`body::before`** — фіксований шар із чотирьох великих золотих
  радіальних пляма-світла, що повільно дрейфує (`transform`, 52 c).
  Фіксований + тільки `transform` — тож скрол не викликає перемальовки.
- **Секції прозорі** (`background:transparent`), тому світло проходить
  крізь них; кожна секція додає власну пляму у своєму куті, і при
  прокрутці світло «переходить» з місця на місце.
- **`.section-edge`** — тонка світлова лінія на стику великих секцій.

Яскравість підібрана за виміром: найсвітліше тло під текстом —
`rgb(38,33,25)`, найгірший контраст золотого заголовка — **7,6:1**
(WCAG AAA вимагає 7:1). Вимикається при `prefers-reduced-motion`.

`node glowcheck.mjs` заміряє контраст тексту, що лежить просто на тлі
секції (не в картці), із зупиненим дрейфом у найяскравішій фазі.

## Калькулятор — один компонент, два місця

`Converter(root, onChange)` у `parts/zz-tail.html` знаходить елементи через
data-атрибути всередині `root`: `data-cur`, `data-amt`, `data-flag`
(`from` / `to`) та `data-swap`. Той самий код працює і на першому екрані,
і у формі заявки — курси (`CUR`, `CROSS`) задаються один раз.

## Купюри долара

У конвертері долар розділено за станом купюр:

- **USD · нові 100 $** — нові купюри номіналом 100 $ (ключ `USD100`)
- **USD · інші купюри** — старіші купюри 2000-х років (ключ `USD`)

Різниця видна прямо у назвах пунктів списку, окрема легенда не потрібна.

## Кнопки

Золоті кнопки (`.btn--light`, `.btn--accent`, `.btn--solid`) використовують
п'ятистопний градієнт `--accent-grad-anim` при `background-size:200% 100%`.
Один період градієнта дорівнює ширині кнопки, тож анімація
`background-position: 0% → 100%` зациклюється без стику.

```css
@keyframes btn-sheen{ from{background-position:0% 50%} to{background-position:100% 50%} }
```

Базова `.btn` задає **`background-color`**, а не `background` — інакше
`.btn:hover` (вища специфічність) стирав би `background-image` золотих
кнопок, і підпис ставав чорним на прозорому тлі.

Анімація вимикається при `prefers-reduced-motion: reduce`.

## Колір тексту та контраст

Увесь текст білий (`--text`, `--text-2`, `--text-3`, `--text-4` = `#ffffff`).
Акцентний колір використовується **тільки як акцент, не як колір для читання**:

| Де | Що |
|---|---|
| `.accent` | виділене слово в заголовку |
| `.ben__num`, `.field__v`, `.route__rate b` | великі цифри-показники |
| `.step__n` | номери кроків 01–03 |
| `.logo__text b` | назва бренду |
| `.delta.up` / `.delta.down` | зростання / падіння курсу |

Темний текст залишено лише на світлих кнопках (білий був би невидимий).

Контраст кожного кольору тексту заміряно відносно реального фону під ним.
Найгірший показник на сайті — **8,0:1** (WCAG AAA вимагає 7:1):
темний підпис на найтемнішому стопі градієнта.

## Вага зображень

Усі зображення — WebP, кожне у розмірі приблизно вдвічі більшому за те,
в якому реально показується (для екранів з подвійною щільністю):

| | було | стало |
|---|---|---|
| Уся папка `images/` | 7,8 МБ | **864 КБ** |
| Одна сторінка повністю | ~7,2 МБ | **≈805 КБ** |

Найбільший виграш — аватари у відгуках: вони показуються 46px, а важили
по 690 КБ (1024×1024). Тепер 110px і ~2 КБ.

`vercel.json` дає статиці добовий кеш зі `stale-while-revalidate` —
повторні візити показують зображення миттєво, а оновлення підхоплюються
протягом доби. HTML лишається без кешу, щоб зміни тексту були одразу.

## Технічні деталі

- Шрифти: Inter Tight (заголовки), Inter (текст), JetBrains Mono (цифри, мітки).
- Прапори валют: вбудований SVG-спрайт (27 бейджів, 12 унікальних прапорів).
- Зображення: `images/*.jpg`, згенеровані `gemini-3-pro-image-preview`.
- Карта: вбудований Google Maps з CSS-фільтром під темну тему,
  перемикається вкладками між трьома відділеннями.
- Мікророзмітка `schema.org/CurrencyConversionService` з трьома локаціями BEST.
- Адаптив від 375px; перевірено на 1440 / 1200 / 1024 / 768 / 480 / 375 —
  без горизонтального скролу.
- Підтримка `prefers-reduced-motion`.

> `node_modules` — символічне посилання на сусідній проєкт (puppeteer для
> скріншотів). Для окремого розгортання достатньо `index.html` та `images/`.
